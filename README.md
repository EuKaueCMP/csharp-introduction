# csharp-introduction

Comprehensive collection of foundational C# exercises, object-oriented programming projects, and architectural transitions to MVC.

## Description

csharp-introduction documents the progressive learning journey in C# and .NET development. It spans from core language syntax and algorithmic problem-solving to advanced Object-Oriented Programming (OOP), domain modeling, database integration (DbFirst), and foundational MVC (Model-View-Controller) application structures developed during coursework.

## Technologies

- **Language:** C#
- **Platforms & Frameworks:** .NET, ASP.NET MVC, Entity Framework Core
- **Database:** SQL Server
- **IDE:** Visual Studio

```text
csharp-introduction/
```

## Key Topics & Progression

1. **Foundational Syntax & Flow:**
   - Primitive data types, operators, conditional structures (`if`/`else`, `switch`), and iterative loops (`for`, `foreach`, `while`).
   - Standard console stream operations (`Console.ReadLine`, `Console.WriteLine`).

2. **Object-Oriented Programming (OOP):**
   - Class design, property accessors (`get`/`set`), and constructor overloading.
   - Encapsulation, inheritance hierarchies, and polymorphic behavior.

3. **Domain Modeling & Systems:**
   - Vehicle management (`SistemaCarrosMVC`), lab equipment tracking (`AurumLab`), and user authentication modules.

4. **Data Persistence & MVC Architecture:**
   - Entity Framework DbFirst modeling and SQL database querying.
   - Separation of concerns across Models, Views, and Controllers.

## Setup & Execution

### Prerequisites
- [.NET SDK](https://dotnet.microsoft.com/download) (version 8.0 or later) or .NET Framework runtime
- [Visual Studio 2022](https://visualstudio.microsoft.com/) with **.NET desktop development** workload

### Running an Exercise
1. Clone the repository:
```bash
git clone https://github.com/EuKaueCMP/csharp-introduction.git
```

2. Open the desired solution (`.sln`) in Visual Studio or navigate into a project directory via terminal and run:
```bash
dotnet run
```
